# 📜 Wishlist Photo

Dépose ici la capture d'écran ou la photo de la liste de souhaits qu'elle t'avait envoyée :

- Nom du fichier : `wishlist.jpg` (ou `wishlist.png`)
- Si tu utilises un nom ou format différent, configure le chemin dans `src/data/gift.ts` :
  ```ts
  wishlistImage: "/wishlist/ta-photo.png"
  ```
