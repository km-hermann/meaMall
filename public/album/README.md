# 📸 Photos pour l'Album Rétrospective des 24 ans de Mea

Voici l'ordre officiel des 8 checkpoints dans `public/album/` :

- `photo-1.jpg` : **Checkpoint 1** (Le Réveil / Les bougies / Le début de fête 🎂)
- `photo-2.jpg` : **Checkpoint 2** (Le look de Milliardaire / Portrait éclatant ✨)
- `photo-3.jpg` : **Checkpoint 3** (L'ambiance de fête / Toast avec les amis 🥂)
- `photo-buffet.jpg` *(ou `photo-5.jpg`)* : **Checkpoint 4** (Se servant au merveilleux buffet 🍽️)
- `photo-brother.jpg` *(ou `photo-6.jpg`)* : **Checkpoint 5** (Avec notre frère à la fête 👦❤️)
- `photo-gifts.jpg` *(ou `photo-7.jpg`)* : **Checkpoint 6** (La photo de ses cadeaux reçus 🎁)
- `photo-7.jpg` *(ou `photo-cameroun.jpg`)* : **Checkpoint 7** (Nostalgie & Pensées du Cameroun 🇨🇲❤️🇩🇪)
- `photo-mum.jpg` *(ou `photo-8.jpg`, `photo-maman.jpg`)* : **Checkpoint 8** (Avec Maman quand elle était au Cameroun 🇨🇲👩‍👧❤️)
- `photo-mama-dangotte.jpg` *(ou `photo-9.jpg`, `photo-bestie.jpg`)* : **Checkpoint 9** (Avec sa Bestie Mama Dangotte durant leur mois en Allemagne 👯‍♀️✨)
- `photo-10.jpg` : **Checkpoint 10** (Sourire d'avenir / Cap sur les 25 ans & le doctorat 👩‍⚕️👑)

*(Formats acceptés : `.jpg`, `.jpeg`, `.png`, ou `.webp`. Tu peux aussi ajuster les légendes et titres dans `src/data/album.ts`).*
