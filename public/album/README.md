# 📸 Photos pour l'Album Rétrospective des 24 ans de Mea

Dépose tes photos de son 24ème anniversaire dans ce dossier `public/album/` :

- `photo-1.jpg` : **Checkpoint 1** (Le Réveil / Les bougies / Le début de fête 🎂)
- `photo-2.jpg` : **Checkpoint 2** (Le look de Milliardaire / Portrait éclatant ✨)
- `photo-3.jpg` : **Checkpoint 3** (L'ambiance de fête / Toast avec les amis 🥂)
- `photo-4.jpg` : **Checkpoint 4** (Souvenir nostalgique / Moment complice 🇨🇲❤️🇩🇪)
- `photo-5.jpg` (ou `photo-buffet.jpg`) : **Checkpoint 5** (Se servant au merveilleux buffet 🍽️)
- `photo-6.jpg` (ou `photo-brother.jpg`) : **Checkpoint 6** (Avec notre frère à la fête 👦❤️)
- `photo-7.jpg` (ou `photo-gifts.jpg`) : **Checkpoint 7** (La photo de ses cadeaux reçus 🎁)
- `photo-8.jpg` : **Checkpoint 8** (Sourire d'avenir / Cap sur les 25 ans & le doctorat 👩‍⚕️👑)

*(Formats acceptés : `.jpg`, `.jpeg`, `.png`, ou `.webp`. Tu peux aussi ajuster les légendes et titres dans `src/data/album.ts`).*
